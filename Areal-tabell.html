1. Algoritme – tenk først, kode etterpå

En algoritme er en presis steg‑for‑steg‑oppskrift for hvordan et problem skal løses. Før du skriver kode, er det lurt å skrive algoritmen med egne ord (pseudokode) på norsk eller engelsk.

Tips: Mange språk (som Python) er basert på engelsk nøkkelord, men selve algoritme‑ideen er den samme uansett språk.

3. Tekst, strenger og print()

print() skriver tekst (strenger) og tall til skjermen. Tekst i Python skrives i anførselstegn ("tekst" eller 'tekst').[web:41][web:43]

3.1 Lag kode for flere linjer tekst

Skriv tre linjer tekst (f.eks. Eple, Pære, Banan), så får du ferdig print()-kode.

3.2 Forskjell på + og komma i print()

I Python vil print("Hei", "på", "deg") automatisk legge inn mellomrom mellom ordene, mens print("Hei" + "på" + "deg") ikke gjør det – der må du legge inn mellomrom selv.[web:43][web:48]

4. Tall, operatorer og regnestykker

I Python har du standard operatorer: +, -, *, /, **, % og //.[web:36][web:38]

  • + : addisjon (pluss)
  • - : subtraksjon (minus)
  • * : multiplikasjon (gange)
  • / : divisjon (gir desimaltall)
  • ** : potens (f.eks. 2**3 = 8)
  • % : rest (modulus), f.eks. 7 % 2 = 1
  • // : heltallsdivisjon, f.eks. 7 // 2 = 3
Denne boksen bruker JavaScript i nettleseren til å etterligne Python for de vanligste regnestykkene, inkludert // (heltallsdivisjon) og ** (potenser).

5. Heltall, desimaltall, int() og float()

I Python er et heltall en int og et desimaltall en float. int(x) fjerner desimalene og gir heltallsdelen, mens float(x) gjør et heltall om til desimaltall.[web:38][web:39]

Oppgavetype: «Hva blir skrevet ut av print(int(3.14))?» – bruk verktøyet til å resonere deg frem til svaret (3), ikke bare gjette.
